Prérequis d'installation

macOS
✓
macOS 12 ou plus récent
✓
Python 3.12+
Vérifiez avec : python3 --version dans le Terminal
⚙️
Ink/Stitch (extension Inkscape)
À installer une seule fois — des instructions sont fournies dans l'app
Windows
✓
Windows 10 ou 11 (64-bit)
✓
Python 3.12+
Téléchargez sur python.org si absent
⚙️
Ink/Stitch (extension Inkscape)
À installer une seule fois — des instructions sont fournies dans l'app

Mac : après le .dmg, faites clic droit → Ouvrir (et non double-clic)
pour contourner le message de sécurité macOS la première fois.
Windows : si SmartScreen s'affiche, cliquez "Informations complémentaires" → "Exécuter quand même".
